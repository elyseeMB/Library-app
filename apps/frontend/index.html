Accueil

Ceci est un prototype de routeur htmx basé sur hx-boost. Tous les liens de la navigation sont de simples <a href> : htmx intercepte le clic, fait un fetch AJAX, remplace le <body> et pousse l'URL dans l'historique.

Clique sur Dashboard ou Profil sans rechargement. Utilise ensuite les boutons précédent / suivant du navigateur : le cache d'historique d'htmx restaure les pages instantanément.

Ouvre la console pour voir les événements htmx déclenchés.
